# Railway Deployment - Required Environment Variables

## Backend Service Variables (Add to Railway)

### Database Configuration (from Railway MySQL Plugin)
```
DB_HOST=<railway-mysql-host>           # e.g., containers-us-west-1.railway.app
DB_PORT=<railway-mysql-port>           # Usually 3306 or custom port
DB_USER=<railway-mysql-user>           # Usually "root"
DB_PASSWORD=<railway-mysql-password>   # Auto-generated by Railway
DB_NAME=bloghub_db                     # Database name
```

### Server Configuration
```
PORT=5000                              # Railway auto-assigns, but set default
NODE_ENV=production                    # Important for optimization
```

### Frontend URL (CRITICAL for CORS)
```
FRONTEND_URL=https://your-vercel-app.vercel.app
CLIENT_URL=https://your-vercel-app.vercel.app
```

### Authentication
```
JWT_SECRET=<your-secure-random-string>  # Generate: openssl rand -base64 32
JWT_EXPIRES_IN=7d                       # Token expiration time (7 days recommended)
SESSION_SECRET=<another-random-string>  # Generate: openssl rand -base64 32
```

### Cloudinary (Image Upload)
```
CLOUDINARY_CLOUD_NAME=<your-cloud-name>
CLOUDINARY_API_KEY=<your-api-key>
CLOUDINARY_API_SECRET=<your-api-secret>
```

---

## Frontend Environment Variables (Add to Vercel)

### API Configuration
```
VITE_API_URL=https://your-railway-app.up.railway.app/api
```

---

## How to Get Values:

### 1. Railway MySQL Database:
- Add MySQL plugin to Railway project
- Copy connection details from Railway dashboard
- Use these for DB_HOST, DB_PORT, DB_USER, DB_PASSWORD

### 2. Generate Secrets:
```bash
# JWT Secret
openssl rand -base64 32

# Session Secret
openssl rand -base64 32
```

### 3. Cloudinary:
- Sign up at https://cloudinary.com (free tier)
- Get credentials from dashboard

### 4. Frontend/Backend URLs:
- Deploy backend to Railway first → get Railway URL
- Deploy frontend to Vercel → get Vercel URL
- Update both services with each other's URLs
